# Osama Abdelaziz — Portfolio

Personal portfolio for a senior Flutter developer. Content comes from the CV: SAK Real Estate, Happy Trip, Axon, Autoly, and NTG Clarity.

## Run

```bash
cd osama_portfolio
flutter pub get
flutter run -d chrome
```

The same project also runs on iOS, Android, and macOS.
